How it works

This is a tiny, self-contained incremental game built with plain HTML/CSS/JS so it can live on GitHub Pages without any backend.

Core resources

Bits are your main number. Clicking the big circle adds +1 bit.

Bytes are earned as milestones: whenever your total bits crosses a multiple of 100, you gain +1 byte (your bits do not reset).

Two upgrade paths

Auto-clickers are bought with bytes and generate bits every second.

Upgrades are bought with bits and increase production for each auto-clicker.

Costs and scaling

Both progression paths get more expensive on purpose, but they scale separately:

  • Auto-clickers: cost doubles each time you buy one (1, 2, 4, 8, … bytes).
  • Upgrades: cost doubles each level (10, 20, 40, 80, … bits).

Production math

The game computes your current production like this:

  • ratePerClicker = 1 + upgradeLevel
  • bitsPerSecond = clickersOwned * ratePerClicker

Every second, it adds bitsPerSecond to your bit total, and awards bytes if you crossed any 100-bit milestones.

Saving without a server

Because GitHub Pages is static hosting, the save data is stored in a cookie. The save includes:

  • bits, bytes
  • auto-clickers owned
  • upgrade level
  • lastOnline timestamp

Offline progression

The game updates lastOnline periodically (at least every 5 minutes, plus when you leave the tab). When you come back, it:

  1. Computes how many seconds you were away.
  2. Calculates the bits you would have earned from auto-clickers during that time.
  3. Adds those bits instantly, awards any milestone bytes, and shows a small notification.

Where to look in the code

  • clicker.html: page layout and UI elements
  • clicker.css: centered layout and the circular click button
  • clicker.js: state, costs, saving, and offline progression
